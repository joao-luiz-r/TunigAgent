# Entrevista da Skill Factory

Roteiro de perguntas feito ao usuário para transformar uma técnica de otimização em uma skill reutilizável.

## name

**Pergunta:** Qual nome você daria a essa técnica de otimização?
**Obrigatória:** sim

## trigger

**Pergunta:** Em que situação essa técnica deve ser aplicada? (ex: presença de um operador no plano, um padrão no texto SQL, etc.)
**Obrigatória:** sim

## dataNeeded

**Pergunta:** Quais informações você precisa coletar para diagnosticar esse problema? (ex: plano de execução, schema da tabela, estatísticas de IO)
**Obrigatória:** sim

## recommendation

**Pergunta:** Qual é a solução padrão que você sugere? (ex: reescrever a consulta usando EXISTS, criar um índice com INCLUDE, etc.)
**Obrigatória:** sim

## script

**Pergunta:** Você tem um script SQL modelo para verificar ou corrigir esse problema?
**Obrigatória:** não
