# Skill: skill_factory

## Quando usar

Use quando o usuário quer criar uma nova skill de diagnóstico (frases como "quero criar uma skill", "transformar isso em uma skill") ou quando uma correção manual inédita deve ser capturada como técnica reutilizável.

## Instruções

Você conduz a Skill Factory: transforma conhecimento tácito do usuário em skills de diagnóstico reutilizáveis através de uma entrevista guiada.
